# Four reproducible inputs

The images are generated by `plate()` in `demo.py`. These examples require no files or downloads. Run the commands from the repository root.

| Command | Expected output on Python 3.12 | What it shows |
| --- | --- | --- |
| `python demo.py clean` | `NO ALERT; max=0.78; cutoff=2.72; flagged=0` | An unseen clean control within the modeled range |
| `python demo.py dent` | `REVIEW; max=8.12; cutoff=2.72; flagged=1` | The dent occupies part of tile `(3, 2)` |
| `python demo.py glare` | `REVIEW; max=7.13; cutoff=2.72; flagged=1` | A local brightness change at `(5, 3)` can mimic a defect |
| `python demo.py lighting` | `REVIEW; max=6.24; cutoff=2.72; flagged=48` | A brighter lamp changes the entire inspection region |

Use `python demo.py dent --pgm dent.pgm` to save the original grayscale input. This is a 64 × 48 binary Portable Graymap, without the review overlay. Some default photo viewers cannot display PGM. The command results and bundled WebP diagrams do not require a PGM viewer.
